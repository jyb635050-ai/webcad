# 视觉一致性记录

对照基准：`docs/webcad-ui-concept.png`  
实装证据：`docs/screenshots/01-empty-start.png`、`02-plate-extruded.png`、`03-export-success.png`

1. **总体布局**：一致。顶部命令区、左侧草图/特征树、中央三维视口、右侧参数/打印/导出、底部状态区均保留；实装把状态文字并入视口底栏，给建模区留出更多高度。
2. **色彩与层级**：一致。使用纯白和冷灰界面、蓝色主操作、绿色通过状态；模型保持浅灰蓝实体和深色孔壁。
3. **字体与密度**：基本一致。实装采用系统中文无衬线字体和紧凑工业软件密度；按钮图标使用项目内嵌 SVG，不依赖图标字体或 CDN。
4. **视口与模型**：一致。等轴测板件、四通孔、圆角边、网格、坐标轴和视图方块均落地；实装额外保留可编辑草图尺寸叠层，强调“尺寸驱动”而非只展示成品。
5. **控制与反馈**：实装更完整。除概念图中的建模、打印检查和四格式导出外，增加新建、示例零件、工程 JSON 导入/导出和明确的导出成功提示。

有意偏差：窄屏不强行压缩成桌面三栏，而改为纵向堆叠，避免工具和参数不可点；这是可用性优先的响应式处理，不改变桌面主视觉。
