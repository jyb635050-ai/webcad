## 五项逐点对照

1. **命令顺序与文案**：概念和实装均固定为“选择面 → 草图 → 完成草图 → 拉伸”，当前步骤蓝色高亮，未到步骤不可点击。
2. **工作区结构**：均为顶部命令链、左侧基准面/草图/特征树、中央主视口、右侧上下文参数。实装保持中央视口占最大面积。
3. **面选择与草图态**：空白启动显示前视、上视、右视三个可拾取基准面；进入草图后自动沿所选面法向观察，只保留二维轮廓、尺寸和草图工具。
4. **拉伸操纵器**：实体面蓝色高亮，透明蓝色预览体沿面法向生成，蓝色箭头可直接拖动；浮动标签和右侧输入框同步显示毫米值。
5. **确认与后续建模**：右侧“确定”为绿色主操作，“取消”为次操作；确认后可再次点实体顶面，创建第二张草图并追加拉伸。

## 首屏文案核对

允许且实际出现：`构形 WebCAD`、`选择面`、`草图`、`完成草图`、`拉伸`、`前视基准面`、`上视基准面`、`右视基准面`、`当前选择`、`在此面新建草图`。

已删除：`示例零件`、`载入示例零件`、模板/账号/云端等与建模主流程无关的入口。

## 有意偏差

- 概念图包含操作系统窗口边框，网页实装不模拟系统标题栏。
- 打印自检和导出在完成实体后才显示；草图和拉伸预览阶段收起，避免干扰当前任务。
- 实装支持窄屏内部横向滚动命令链；390px 视口页面横向溢出实测为 0。

## 2026-07-31 草图贴面与切除复核

1. **基准面贴合**：进入草图后隐藏会造成双平面错觉的有限旧基准面，只显示覆盖编辑视口的当前草图平面；截图 `05-sketch-on-plane.png` 中轮廓、尺寸和网格处于同一平面。
2. **坐标与相机**：相机视线与所选面法向点积实测为 `1.0`；80×40mm 矩形的 SVG 四角与三维平面投影最大误差为 `0.0px`，草图偏置为 `0mm`。
3. **实体面草图**：截图 `09-circle-sketch-attached.png` 中实体顶面保持为蓝色底面，圆轮廓与尺寸直接落在顶面上，不再悬浮于三维场景。
4. **切除预览**：截图 `10-cut-depth-preview.png` 使用红色透明减料体与向内箭头；右侧仅显示切除深度、贯穿全部、确定切除和取消，沿用既定检查器密度与按钮体系。
5. **切除结果**：截图 `11-blind-hole-result.png` 显示实体顶面真实盲孔；特征树包含切除特征，三维边线连续，没有残留预览体。
6. **响应式与文案**：没有新增首屏入口或示例模型；新增文案只在草图/切除上下文出现，1536px 与 390px 页面横向溢出仍为 0。
